# 🌹 TrueLetter - 3D Interactive Floral & Love Letter Experience

An enchanting 3D web experience featuring a handcrafted white rose bouquet with an authentic parchment flip card that opens to reveal a romantic 3-stanza poem with illuminated drop caps.

Built with **React**, **Three.js**, **Vite**, and **Tailwind CSS**.

---

## ✨ Features

- **🌹 Handcrafted 3D Rose Bouquet**: 13 white tea roses in an organic spiral staircase arrangement, enveloped in luxury onyx wrapping with gold accents.
- **📜 3D "Letter of Truth" Gift Card**: Embedded on the bouquet's ribbon knot. Tap to open an interactive modal flip card.
- **📖 3-Stanza Poetry Spread**: The back of the flip card features a romantic 3-stanza poem, complete with classical rubricated drop caps (**E**, **I**, **T**) on authentic paper texture.
- **🎵 Synthesized Ambient Romantic Music**: Built-in Web Audio API synthesizer that plays a soothing, peaceful ambient background soundtrack.
- **📱 Fully Responsive & Touch-Optimized**: Custom-framed for every smartphone, tablet, laptop, and desktop. Includes pinch-to-zoom, 360° orbit rotation, tap-to-flip, and gesture discrimination.
- **🎨 Bouquet Atelier (Customizer Drawer)**: Adjust rose colors, wrap colors, ribbon styling, fairy dust particles, and auto-rotation turntables in real time.
- **📸 High-Resolution Snapshot Tool**: Capture and download studio-quality screenshots of your bouquet.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation

```bash
git clone https://github.com/Eljohn-Loterte/trueletter.git
cd trueletter
npm install
```

### Development Server

Run the local Vite development server:

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build

Create an optimized production bundle:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
